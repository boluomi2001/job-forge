# 平台适配

本项目的技能基于开放的 [Agent Skills](https://agentskills.io) 约定（`SKILL.md` + YAML frontmatter + `references/` 子目录），因此凡支持该约定的 runtime 都能直接使用。

## 一、技能目录与实测状态

| runtime | 用户级技能目录 | 项目级技能目录 | 状态 |
|---|---|---|---|
| **WorkBuddy** | `~/.workbuddy/skills/` | 同左（用户级） | ✅ 已实测（v1.0.0） |
| **Claude Code** | `~/.claude/skills/` | `<project>/.claude/skills/` | 🧪 按约定路径，未逐一实测 |
| **Cursor** | `~/.cursor/skills/` | `<project>/.cursor/skills/` | 🧪 同上 |
| **Codex** | `~/.codex/skills/` | `<project>/.codex/skills/` | 🧪 同上（另提供 `.codex-plugin/` 插件清单） |
| **OpenCode** | `~/.config/opencode/skills/` | `<project>/.opencode/skills/` | 🧪 同上 |
| **Gemini CLI** | `~/.gemini/skills/` | `<project>/.gemini/skills/` | 🧪 同上 |

> "🧪 未实测" 的含义：路径按各 runtime 公开约定填写，脚本不依赖 runtime 私有接口；若你的版本路径不同，用 `--dir` 指定即可。

## 二、一键安装

```bash
# 自动探测（按 workbuddy → claude → cursor → codex → opencode → gemini 顺序找已存在的目录）
bash scripts/install.sh

# 指定 runtime
bash scripts/install.sh -t claude
bash scripts/install.sh -t all              # 六个全装
bash scripts/install.sh --dir "$HOME/my-skills"   # 自定义目录

# 只装编排层，不拉上游（离线或已有 ASu 时用）
bash scripts/install.sh -t workbuddy --no-asu

# 预演
bash scripts/install.sh --dry-run
```

Windows（PowerShell 5.1 与 7+ 均可）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -Target workbuddy
powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -Target all -NoAsu
powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -Dir "D:\skills"
```

## 三、安装脚本做了什么

1. 复制 `skills/job-forge/` 到 `<skills-dir>/job-forge`
2. 拉取上游 [ASu-skills](https://github.com/Hisn00w/ASu-skills) 到 `<runtime-root>/asu-skills`（`git clone --depth 1`，失败则回退 zip，含镜像）
3. 复制其 8 个执行技能到 `<skills-dir>/`
4. 让 `<runtime-root>/assets`、`<runtime-root>/references` 可解析（ASu 的技能用 `../../assets/` 引用资源：18 套简历模板、进度表、Logo 等）
5. 打印后续操作

**为什么需要第 4 步**：ASu 官方桥接脚本只软链 `skills/`，不处理 `assets/`，导致简历模板会回退成简陋后备模板。本项目补上了这一步（`--link` 时用软链，否则复制）。

## 四、收敛自动入口

装好后默认所有技能都能自动触发。若你希望**只对 job-forge 说人话**，把 8 个子技能设为手动：

### WorkBuddy

编辑 `~/.workbuddy/settings.json`，在 `skillOverrides` 中加入（改前备份）：

```json
{
  "contributor": "user-invocable-only",
  "evidence-recap": "user-invocable-only",
  "project-guide": "user-invocable-only",
  "great-resume": "user-invocable-only",
  "make-resume": "user-invocable-only",
  "job-match": "user-invocable-only",
  "interview": "user-invocable-only",
  "offer": "user-invocable-only"
}
```

三种档位（对模型侧均禁用自动调用）：

| 值 | 效果 |
|---|---|
| `off` | 完全关闭 |
| `user-invocable-only` | 你手动点名可用，模型不自动触发（列表仍展示） |
| `name-only` | 列表仍展示名称，模型侧同样不调用 |

### 其他 runtime

多数 runtime 没有等价的开关。可选做法：
- 只把 `job-forge` 放进项目级技能目录，8 个子技能放用户级；
- 或者反过来：项目里只留 `job-forge`，需要时手动点名子技能。
- 若不介意偶发抢触发，保持默认即可，功能不受影响。

## 五、资源路径速查（排错用）

| 内容 | 路径 |
|---|---|
| 本技能 | `<skills-dir>/job-forge/` |
| 上游仓库 | `<runtime-root>/asu-skills/` |
| 简历模板（18 套） | `<runtime-root>/assets/templates-html/` |
| 默认 ASu 简历壳 | `<runtime-root>/assets/asu-resume/template.html` |
| 简历构建脚本 | `<runtime-root>/asu-skills/scripts/build-asu-resume.mjs` |
| 投递进度表 | `<runtime-root>/assets/application-tracker.html` |
| 账本模板 | `<runtime-root>/assets/career-claim-ledger-template.json` |
| 账本校验脚本 | `<runtime-root>/asu-skills/scripts/validate_claim_ledger.py` |

其中 `<runtime-root>`：WorkBuddy = `~/.workbuddy`，Claude Code = `~/.claude`，以此类推。

## 六、卸载

```bash
bash scripts/uninstall.sh -t workbuddy            # 卸 job-forge + 8 个子技能
bash scripts/uninstall.sh -t workbuddy --keep-asu # 保留上游仓库与资源
```

PowerShell：`powershell -ExecutionPolicy Bypass -File scripts\uninstall.ps1 -Target workbuddy`

## 七、已知限制

| 限制 | 说明 | 规避 |
|---|---|---|
| `job-apply`（浏览器自动填表）不可用 | 上游该技能依赖浏览器扩展与桥接脚本，纯技能目录无法提供运行环境 | 用 job-forge 的填表数据包 + 手动提交 |
| Windows 软链需开发者模式/管理员 | `--link` 可能失败 | 脚本自动回退复制；或直接用默认 `copy` |
| 上游为中文语境 | 面经来源覆盖中国大陆市场（小红书/牛客/脉脉） | 海外岗位主要用 M1/M2，M4 效果有限 |
| 上游更新需重跑安装 | 复制模式下不跟随上游 | 用 `--link`，或定期重跑 `install.sh` |
