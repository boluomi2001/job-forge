# 依赖清单

## 一、核心：零依赖

本仓库的技能本体是**纯 Markdown**（`SKILL.md` + `references/*.md`），不需要安装任何包、不需要 API Key、不需要联网即可被 runtime 加载。

| 依赖 | 版本要求 | 是否必需 | 用途 |
|---|---|---|---|
| 支持 Agent Skills 的 runtime | — | ✅ 必需 | 运行技能（WorkBuddy / Claude Code / Cursor / Codex / OpenCode / Gemini CLI） |
| bash ≥ 4（macOS/Linux/Git Bash）或 PowerShell ≥ 5.1 | — | ⚠️ 仅安装时需要 | 跑 `scripts/install.*` |
| git | ≥ 2.20 | ⭕ 可选 | 拉取上游；缺失时自动回退 zip 下载 |
| curl | — | ⭕ 可选 | zip 下载回退 |
| unzip | — | ⭕ 可选 | zip 解压（Windows 用 Expand-Archive） |

> 手动复制 `skills/job-forge/` 到技能目录的话，**连脚本都不需要**。

## 二、上游执行层（安装脚本自动拉取）

`--no-asu` 可跳过。跳过时 M1–M5 的方法仍可用，但以下能力缺失：

| 能力 | 缺失后果 |
|---|---|
| 简历模板 18 套 + 构建脚本 | 只能手写 HTML 简历 |
| 主张—证据账本模板与校验器 | 主档 P1 只能人工维护 |
| 模拟面试 harness 细则 | M5 退化为普通追问 |
| 投递进度表 | 只能自己建表 |

上游运行时依赖：

| 依赖 | 版本 | 何时需要 |
|---|---|---|
| Node.js | ≥ 18 | 生成/内联简历 HTML（`build-asu-resume.mjs`、`inline-template.mjs`） |
| Python | ≥ 3.9 | 校验主张—证据账本（`validate_claim_ledger.py`） |
| GitHub CLI `gh` | 任意近期版本 | 开源贡献流程里查 issue / PR / CI 状态（可选） |

## 三、可选增强

| 依赖 | 用途 | 装不装的区别 |
|---|---|---|
| `gh`（已登录） | M1 贡献路径、PR/CI 状态查询 | 不装则只能靠网页手工查 |
| 浏览器 | 打开生成的 HTML、打印 PDF | 必需（出简历 PDF 要用浏览器打印） |
| 中文字体 | 简历 PDF 不出现方框 | 系统通常自带（苹方 / 微软雅黑 / 思源黑体） |

## 四、不需要什么

- ❌ 不需要 OpenAI / Anthropic / 任何模型 API Key（技能由 runtime 自己的模型执行）
- ❌ 不需要数据库、服务端、账号体系
- ❌ 不需要 npm/pip 安装任何本项目依赖（`package.json` 只用于上游脚本调用，本项目不含）

## 五、环境自检

```bash
# 1) 技能是否就位
ls ~/.workbuddy/skills/job-forge/SKILL.md        # macOS/Linux
# dir %USERPROFILE%\.workbuddy\skills\job-forge   # Windows

# 2) 上游资源是否可解析
ls ~/.workbuddy/assets/templates-html/*.html | wc -l    # 期望 18

# 3) 可选工具
node -v; python --version; gh --version
```
