# 案例库（校准用）

> 四个原型案例，来自原始框架。遇到新行业时先问：它更像哪一个？像，就直接套用对应结论路径。

## 案例 1：无人自助洗车机 —— 一层即排除

| 层 | 发现 | 判据 |
|---|---|---|
| 表层·盈利 | 设备 10–15 元/次，日洗 20–30 辆，单日营收 200–300 元；扣场地月租、水电、耗材、折旧后月利极薄 | 单位经济模型为负或极薄 |
| 表层·真赚钱点 | 真正赚钱的是**卖设备给加盟商**、靠**预充会员卡套现金流** | 收入不来自主营服务 → 商业模式是"卖给想赚钱的人" |
| 表层·容量 | 油站/停车场等优质点位已被头部瓜分，剩余点位车流差或租金高 | 零和抢存量，不是增量赛道 |
| 表层·监管 | 污水排放政策使成本翻倍 | 合规成本吃掉毛利 |

**结论路径**：一层三问全部不利 → 排除，不必挖第二层。
**可迁移信号**：凡是"赚钱靠加盟商/培训/预收卡"的行业，先怀疑，后验证。

## 案例 2：电力/新能源 —— 二层决定落点

| 环节 | 位置 | 特征 | 岗位 |
|---|---|---|---|
| 上游 | 高端设备研发（光伏逆变器、特高压变压器） | 效率/成本/安全性的根子卡在设备；人才缺口大、通道清晰、薪资高 | 研发、硬件、算法 |
| 中游 | 电网系统 | 稳定，但越往上越拼资历，薪资低于上游研发 | 调度、运行、规划 |
| 下游 | 电站运维、现场电气维护、工厂电工 | 用体力与时间换钱 | 运维、检修 |

**结论路径**：同一专业跨环节薪资差 3–5 倍 → 转行的真正目标不是"进入行业"，而是"进入高价值环节"。
**可迁移信号**：链条上越靠近"定义标准/定义性能"的环节，利润与薪资越集中。

## 案例 3：奶茶 —— 三层读出规则

| 层级 | 打法 | 结果 |
|---|---|---|
| 头部（如蜜雪） | 早年重资自建工厂 + 自建物流，支撑万店规模 | 靠供应链成本守住龙头 |
| 腰部（区域品牌） | 深耕区域、差异化小料，不与全国龙头硬拼规模 | 在区域优势里建小壁垒 |
| 尾部（网红品牌） | 营销造势 + 单款爆品，无供应链控成本、无稳定渠道点位 | 热度过后被复制、被淘汰 |

**结论路径**：入行前先问"我打算走这三条路里的哪一条"——头部路要资本，腰部路要区域资源，尾部路是死路。
**可迁移信号**：尾部死亡原因清单（无成本优势 / 无渠道点位 / 单一爆品 / 纯营销）= 这个行业的死亡禁区。

## 案例 4：运动康复 —— 四层看到宏观

| 层 | 观察 |
|---|---|
| 竞争战略 | 商业连锁机构 vs 医院共建机构，打法根本不同 |
| 长期动态 | 单次项目只得到某时点门店数/客单价/复购率；长期跟踪才看得见"医疗资质优势如何放大""连锁下沉哪些起效、哪些因人才复制速度不够而失效" |
| 外延传导 | 商业健康险是否打开付费天花板；健身行业周期如何传导客流；养老服务下沉是否催生老年慢病康复增量；可穿戴设备是教育需求还是替代线下 |
| 宏观 | 人口结构 + 健康消费升级下，康复从小众运动配套变成大众健康刚需的可能性；消费预算收缩期谁被优先保留 |

**结论路径**：四层的终点是宏观。所有行业机会本质是时代红利——政策导向、人口结构、产业周期共同作用的产物。
**可迁移信号**：一个行业的"天花板"几乎总能被上游支付方（医保/保险/补贴/企业预算）决定。

# 方法补强三件套（原框架未给的工具）

## 费雪·闲聊法（补 Phase 3 定性调研）
不看管理层怎么说，看利害关系人怎么说：客户、供应商、竞争对手、前员工、行业协会。
> 关键：大多数人在"说的话不会被引用"时最坦率。面试现场就是一次合法闲聊。

## 波特·五力 + 价值链（补 Phase 2 结构判断）
现有竞争强度、新进入者威胁、替代品威胁、上游议价、下游议价——五力解释"为什么这行天生薄利"。
价值链拆解解释"薄利为什么集中在某一环节"。

## 多尔西·护城河（补 Phase 3 壁垒量化）
四类：无形资产（品牌/专利/牌照）、转换成本、网络效应、成本优势。
验证标准：**定价权 + 高 ROIC + 低资本消耗**三者同现才算真护城河，缺一即为伪壁垒。
