# 四层挖掘执行卡（检索动作 + 数据源 + 判定阈值）

> 用法：每层照单执行，做完打勾。数据源可用性会变，失效就换同类。

## 数据源总表

| 类型 | 来源 | 用来回答 |
|---|---|---|
| 公司财务 | 巨潮资讯（A股公告/年报/招股书）、公司 IR 页、SEC EDGAR（美股）、港交所披露易 | 成本结构、毛利率、收入构成 |
| 公司底色 | 企查查 / 天眼查（股权、诉讼、行政处罚、分支机构） | 真实控制关系、合规风险 |
| 电话会/管理层口径 | 年报业绩说明会、earnings call 纪要、股东大会问答 | 战略意图与对变化的反应 |
| 岗位与薪资 | BOSS直聘 / 猎聘 / 拉勾 / 领英（同岗跨环节对比） | 利润池代理指标、薪资分位 |
| 在职评价 | 脉脉、看准类社区、知乎/小红书垂直帖 | 组织真实状态（需交叉验证，单条不可信） |
| 行业规模 | 国家统计局、行业协会白皮书、券商研报（慧博/发现报告类聚合）、199it、Statista | 容量与渗透率（注意口径） |
| 政策 | 部委官网、地方实施细则、标准委 | 准入与合规成本 |
| 竞品动态 | 公司公众号/发布会、招聘 JD 变化、专利检索 | 战略动向的早期信号 |

> **招聘 JD 是最被低估的免费情报**：岗位数量、JD 措辞、薪资带宽的变化，比任何研报都更早反映一家公司在扩张还是收缩。

## Phase 1 执行卡：表层三问

- [ ] 找到该行业最小可运营单元（一台设备 / 一家门店 / 一个客户 / 一条产线）
- [ ] 列该单元的成本项与收入项，算单月/单年净利
- [ ] 判断"真正赚钱的是哪一项"：主营服务 / 卖设备 / 加盟费 / 预收现金流 / 培训 / 补贴
- [ ] 市场容量用「保有量 × 渗透率 × 频次」自己乘一遍，不用二手"市场规模"
- [ ] 查准入：需要什么资质/牌照/标准？环保安全约束？
- [ ] 结论：能赚 / 难赚 / 靠非主营赚；增量 / 存量 / 萎缩；合规成本量级

**止损阈值**：单位模型为负且无提价空间；或渗透率已高且优质点位/客户被瓜分完；或合规成本 ≥ 毛利 → 排除。

## Phase 2 执行卡：产业链利润池

- [ ] 画上下游链条（≥3 环），每环列 2–3 家代表公司
- [ ] 每环列对应岗位清单（这是转行落点的关键）
- [ ] 用毛利率、集中度（CR3/CR5）、账期、技术壁垒四项打分
- [ ] 招聘网站交叉验证：同专业岗位跨环节薪资差几倍？
- [ ] 结论一句话：最值钱的位置是 ____，因为 ____

**判定阈值**：某环节 CR3 > 50% 且毛利率显著高于链条均值 → 该环节掌握定价权；全链条都在打价格战 → 赛道本身不值得重仓时间。

## Phase 3 执行卡：公司四层拆解

横向三分层：
- [ ] 头部 3 家：靠什么守位（规模/自建供应链/牌照/品牌/网络效应）
- [ ] 腰部 2–3 家：差异化在哪（区域/人群/服务深度）
- [ ] 尾部：近 2–3 年退出的玩家死于什么（列死亡清单）

纵向四问（对目标公司）：
- [ ] 成长路径：起家方式、关键节点、扩张路线（规模 vs 差异化；重 vs 轻）
- [ ] 成本结构：成本大头在哪、收入构成、毛利率/净利率、有无定价权
- [ ] 核心壁垒：多尔西四类中的哪一类；**近 3 年毛利率与市占率走势**判断变宽还是变窄
- [ ] 对变化的反应：过去 3 年最大冲击 + 应对动作 + 结果

**伪壁垒识别**：有护城河应同时满足「定价权 + 高 ROIC + 低资本消耗」。只靠高市占率但长期不赚钱 → 不是护城河，是包袱。

## Phase 3.5 执行卡：岗位层

- [ ] 该岗位在价值链哪一环？成本中心 or 收入中心？
- [ ] 可替代性：能否外包 / 自动化 / 上级兼做？
- [ ] 薪资分位：查 3 个招聘平台同岗三档（初级/中级/高级）
- [ ] 考核口径：这个岗位的 KPI 是什么（从 JD 与面试中反推）
- [ ] 面试考点：5 个专业问题 + 3 个行为问题（按 JD 关键词倒推）

## Phase 4 执行卡：长期与外部

- [ ] 头部公司 3–5 年动向序列（门店/产能/研发/招聘/资本动作）
- [ ] 三条传导链：上游成本 → 毛利；邻业周期 → 客流；政策/人口/消费预算 → 需求结构
- [ ] 区分：短期风格炒作 vs 长期结构性机会
- [ ] 结论一句话：时代红利 / 周期陷阱

## 时间分配参考

| 可用时间 | 做到哪 | 每层耗时 |
|---|---|---|
| 1 天 | Phase 1 + 2 + 3.5 | 2h / 2h / 2h |
| 3 天 | 加 Phase 3（仅目标公司） | 各 3–4h |
| 7 天+ | 四层 + 对标公司 + 闲聊验证 | 各 5h+ |

## 闲聊验证问题包（费雪式，面试与非正式交流通用）

1. 你们这个环节，最近一年最大的变化是什么？
2. 这行里你最佩服哪家？佩服哪一点？
3. 现在进来的人最容易低估什么？
4. 头部那家最强的地方，你认为是 ____ 吗？（给一个具体假设让对方纠偏）
5. 如果让你给一个准备转行进来的人一句提醒，会是什么？
