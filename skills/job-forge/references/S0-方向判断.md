# S0 · 方向判断（考古四层法 + 止损）

> 目标：在花时间之前，判断这行/这家公司/这个岗位值不值得投入。
> 输出：主档 P0 一节 + 一句判决。
> 时间：速准档跳过；标准档做到第 2 层；深研档走完四层。

## 核心原则

1. **分层不是流程，是止损机制**。任一层发现硬伤，立即出"排除"结论。
2. **利润不均匀**。"行业赚钱" ≠ "你能赚钱"，必须定位到环节。
3. **静态截面会骗人**。判断"壁垒变宽还是变窄"必须看 3–5 年序列。
4. **80% 定律**。公开信息最多给你 80%，剩下 20% 只能在面试里问出来。
5. **不编数字**。要么给可指名的来源，要么写"估算，方法如下"。

---

## 第 1 层：表层三问（几乎全公开）

**Q1 能不能赚钱**
- 拆最小可运营单元：客单价 × 频次 −（场地/人力/耗材/获客/折旧）
- 必追：真正赚钱的是主营，还是**卖设备 / 收加盟费 / 预收会员卡 / 做培训**？
- 输出：一句话盈利模式 + 单位经济模型

**Q2 能不能持续增长**
- 自己乘一遍：保有量 × 渗透率 × 频次（不用二手"市场规模 XX 亿"）
- 必追：**增量赛道还是零和抢存量**？优质点位/客户/渠道是否已被瓜分完？
- 输出：增量 / 存量 / 萎缩 + 依据

**Q3 能不能合法做**
- 准入、牌照、标准、环保安全约束
- 必追：监管是让成本翻倍，还是把不合规玩家清出去（反而利好头部）？
- 输出：合规成本量级 + 政策方向

> **止损**：任一为"否"且无改善路径 → 排除，3 句话收工。

---

## 第 2 层：产业链利润池

1. 画链条：上游 → 中游 → 下游 → 终端，每层 2–3 个代表玩家 + **对应岗位清单**（转行的落点在这一栏）
2. 标利润池：毛利率 > 环节集中度（CR3/CR5）> 账期 > 技术壁垒，四项交叉
3. 薪资法验证：同专业岗位跨环节薪资差几倍？差 3–5 倍说明价值极度不均
4. 输出：最值钱的位置是 ___，因为 ___

**常见陷阱**：渠道/牌照环节抽走大部分利润；平台型行业利润池在流量分配方而非供给侧。

---

## 第 3 层：公司四层拆解

先横向三分层（5 分钟）：

| 层级 | 看什么 | 结论指向 |
|---|---|---|
| 头部 | 靠什么守位（规模/自建供应链/牌照/品牌/网络效应） | 行业真实壁垒 |
| 腰部 | 怎么差异化活下来（区域/人群/服务深度） | 可行突围路径 |
| 尾部 | 为什么死（无成本优势/无渠道点位/单一爆品/纯营销） | 死亡清单 |

再对目标公司纵向四问：

1. **成长路径与战略选择**：靠什么起家、关键节点、规模扩张 vs 差异化、重资产 vs 轻资产
2. **成本结构与盈利来源**：成本大头在哪、收入构成、毛利/净利率 → 钱从哪来
3. **核心壁垒**：无形资产 / 转换成本 / 网络效应 / 成本优势；**近 3 年毛利率与市占率走势**判断变宽还是变窄
4. **对变化的反应**：过去 3 年最大冲击 + 应对 + 结果

**伪壁垒识别**：定价权 + 高 ROIC + 低资本消耗，三者同现才是护城河。

---

## 第 4 层：长期与外部传导

1. 拉长战线：头部 3–5 年动向序列（布局加注/收缩、人才进出、资本进出）
2. 三条传导链：
   - 上游成本（算力/芯片/原材料）→ 毛利
   - 相邻行业周期 → 客流/预算
   - 政策 / 人口 / 消费预算收缩 → 需求结构（谁被优先保留，谁最先被砍）
3. 输出：**时代红利 / 周期陷阱** + 三条链

---

## 面试怎么用（关键）

四层法的价值一半在判方向，一半在**变成能说出口的观察**：

| 层 | 面试可用的表达 |
|---|---|
| 表层 | "我看你们主要收入其实来自 X 而不是 Y" |
| 产业链 | "这个环节的毛利被上游/渠道吃掉了，所以你们选择了 Z 路径" |
| 公司 | "你们前年自建了 XX，我理解是为了守住成本，代价是扩张速度" |
| 长期 | "如果算力成本继续降，你们现在的护城河会变宽还是变窄？" |

第 4 层那句最好用——它同时展示你懂业务、懂趋势，还给了面试官一个愿意深聊的钩子。

## 时间分配

| 可用时间 | 做到哪 |
|---|---|
| 2 小时 | 第 1 层 + 第 2 层（够判断"该不该投"） |
| 1 天 | 加第 3 层的目标公司四问 |
| 3 天+ | 四层 + 3 家对标 |
